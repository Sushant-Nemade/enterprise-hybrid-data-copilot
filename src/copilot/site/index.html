Digest-Bound Human-in-the-Loop (HITL) Approval State Machine (HITL-STATE-4 / HITL-DRIFT-SHA)

Step through the transactional SQLite state machine (DRAFT -> PENDING_APPROVAL -> APPROVED / REJECTED) bound to SHA256(normalized_question || sql_snapshot_sha256 || sorted_passage_sha256s || answer_sha256), and simulate an upstream SQL table refresh that automatically invalidates a prior approval.
